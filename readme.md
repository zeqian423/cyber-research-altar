# ⛩️ Cyber Research Altar (赛博科研贡台)

## 🌟 核心特色 (Features)

- **⚡ 全息赛博语言学之神**：语言学赛博十字架 SVG 悬浮全息投影。
- **🍔 丰富科研贡品库**：
  - **学术神器**：WoS / ВАК 论文、0 Warning 自动化提取脚本、$p < 0.05$ 显著签、审稿人的肯定。
  - **续命神器**：冰美式、金拱门、冰镇格瓦斯、科研辣条、俄式红茶与大红肠。
- **🧘 电子木鱼与功德系统**：实时积累科研功德，敲击积累学术正能量。
- **🔮 语言学 PhD 专属求签**：随机生成针对语料库抽取、卡方检验、盲审意见（Revision）、盲审答辩的赛博保佑签文。
- **🗑️ 一键交互控制**：支持动态上供、上限控制与一键清空贡品。

---

## 🚀 快速使用 (Quick Start)

### 1. 本地运行
直接下载项目中的 `index.html`，在任意现代浏览器中双击打开即可使用。

### 2. GitHub Pages 一键部署
1. Fork 或 Clone 本仓库：
   ```bash
   git clone https://github.com/your-username/cyber-research-altar.git
   ```
2. 进入仓库设置 **Settings** -> **Pages**。
3. 将 **Branch** 设置为 `main`（或 `master`），Root 目录设为 `/` 并保存。
4. 稍等片刻即可通过 `https://<your-username>.github.io/cyber-research-altar/` 在线体验！

## 🛠️ 技术栈 (Tech Stack)

- **HTML5 & Pure CSS3**：采用霓虹赛博朋克风格配色、动态 Glow 滤镜与 SVG 扫描线视效。
- **JavaScript (Vanilla JS)**：轻量级零依赖，支持贡品状态动态管理与功德计数。
